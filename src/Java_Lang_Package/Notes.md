Object class acts as root for java class hierarchy</p>

#### Why Object Class is Root Class in Java
1. String class contains method which are applicable only  for string Object
2. Object class contains method which are applicable for any java Object

The most commonly required methods for every java class(whether it is preDefined or customizedClass)
are defined in a separate class which is nothing but Object Class. Every class in java is either 
directly or indirectly child class of Object class so that Object class methods by default available 
to every java Class hence Object class is considered as root of all java classes

If our class doesn't extend any other class then only our class is directly child class of object
``Class A{}``  is a direct child of Object
**If our class extends any other class then our class is indirect Child class of Object**

We can use toString() method to get String representation of object
``String s = obj.toString();``
whenever we are trying to print object reference internally to string method will be called
`Student s = new Student();
System.out.println(s.toString())`

``
package Java_Lang_Package;

public class Student {
String name;
int rollNo;

    public Student(String name, int rollNo) {
        this.name = name;
        this.rollNo = rollNo;
    }

    public static void main(String[] args) {
        Student s = new Student("Dhanaji",101);
        Student s1 = new Student("Sambhaji",102);

        System.out.println(s.toString());
        System.out.println(s1.toString());
    }

}
``
<p>If our class doesn't contain toString() method then object class toString() method will be execute</p>
<p>In above example Object class toString() method will be executed which is implemented as follows</p>

``public String toString() {
    return getClass.getName() +  "@" + Integer.toHexString(hashcode());  
    }``
<p>Based on our requirement we can override toString() method to provide our string representation </p>
<p>whenever we are trying to print Student Object reference to print his Name and RollNo </p>
<p>You have to override toString() method as follows</p>

``
@Override
    public String toString(){

        return "This is student with name : "+name +" and Role Number is "+rollNo;
    }
``
