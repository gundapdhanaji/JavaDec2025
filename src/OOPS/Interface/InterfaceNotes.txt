
relationship between interface and class
1) one class extends one class
2) one class implements multiple interfaces
3) one interface implements multiple interfaces
4) If one abstract class implements 1 or more interfaces,
    then it's not mandatory for that abstract child class to provide method implementation of
    abstract methods of interfaces.
5) If one non-abstract class implements 1 or more interfaces,
    then it's mandatory for that non-abstract child class to provide method implementation of
    abstract methods of interfaces
